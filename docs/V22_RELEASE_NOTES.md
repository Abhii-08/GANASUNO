## Use
- Settings > More features (v5–22) > Batch 22 · catalogue, artwork and sync. The new submenu exposes alternate recordings, combined metadata, curator channel playlists, channel subscription checks, authorized animated artwork, cache statistics/clear, and direct audio integrity checking. Waveform accessibility and tempo selection are in Now Playing / track analysis. Artist pagination appears in the MusicBrainz catalogue. Room drift adjustment occurs when Follow host playback is enabled.
- Public catalogue requires your own API key. For subscription sync, enable YouTube Data API for your own authorized OAuth client and obtain a short-lived access token with an appropriate scope (e.g. https://www.googleapis.com/auth/youtube.force-ssl). Use only your own authorized account, enter the exact channel ID and local artist, check the status, then confirm any remote mutation. This is an advanced manual token workflow, not sign-in; the token is kept in memory, not logged or saved to backups, and is sent only to Google. The app does not obtain or refresh tokens. If Google confirms a remote update but local update is interrupted, check status again and use Match local only.
- Remote artwork accepts only direct HTTPS GIF/WebP URLs, no redirects, MIME/type and actual animation validation. Imported covers take precedence over downloaded cached covers. Remote cache max 32 MiB (old entries evicted); clearing does not remove imported files or audio. Android 9+.
- Offline audio: use files you own or have permission to save; the optional SHA-256 must be an independently known 64-digit hexadecimal digest (or leave blank/none). No service restrictions bypassed.
- Native desktop (optional): `cd desktop`, `python -m pip install -r requirements-native.txt`, `python native_player.py`. Windows launcher `Open-Native-Windows.bat` after dependencies installed. The Qt player is separate from the existing browser companion; only local audio is supported. OS codec availability and GUI execution are not verified. No installer provided.
