## GANASUNO 1.1

First public Android release. Requires Android 8.0 or later.

- Download `GANASUNO.apk` and open it to install using Android's confirmation screen.
- `GANASUNO-v1.1-universal.apk` is an identical copy with a versioned filename.
- `SHA256SUMS.txt` verifies both APK filenames and `Corresponding-Source-v1.1.zip`.
- The source ZIP accompanies this release and is available without charge from the same release page.

Player transport remains visible while track details scroll. When Endless artist mix is enabled, Next can refill the queue at the last track.

For an in-place update, the previous install must have the same application ID and signing certificate. The app offers newer stable releases by version code when update checks are enabled.
