# External service review for v1.1

| Integration | Release evidence needed | Compliant option if permission is unavailable |
| --- | --- | --- |
| YouTube and YouTube Music search, stream extraction, background audio and optional transient playback cache | Document authorization for the exact access, playback and caching modes and relevant content rights. YouTube's general terms restrict automation, downloads and access to content outside the permitted service. Its API policies restrict offline copies, separated audio and background players when using YouTube API Services. Paid subscription terms apply to Premium features. [General terms](https://www.youtube.com/t/terms) · [API policies](https://developers.google.com/youtube/terms/developer-policies) · [Paid service terms](https://music.youtube.com/premium/restrictions) | Open results in the official service or use an approved visible player under the applicable terms. Use user-owned files or licensed feeds for background and offline playback. |
| User-imported audio, direct audio/video URLs and public RSS enclosures | Confirm user and content rights for saving, exporting and playing the file. The existing offline paths use imported files or direct inputs and ask users to use authorized media. | Use user-owned files and feeds that grant the relevant rights. |
| LRCLIB and lyrics.ovh | Confirm scope for displaying, caching, exporting or sharing lyrics. LRCLIB documents API access, rate limits and copyright reporting. Obtain evidence for the lyrics uses and equivalent provider terms or permission for lyrics.ovh. [LRCLIB API](https://lrclib.net/docs) | Offer user-supplied lyrics and licensed lyrics services. |
| MusicBrainz, Last.fm, SponsorBlock and Return YouTube Dislike | Verify credentials, attribution, rate limits, storage, redistribution and privacy requirements for the exact requests. Last.fm requires attribution and terms review for commercial use. Check what track, account and playback metadata leaves the device. [Last.fm API terms](https://www.last.fm/api/tos) | Use authorized metadata integrations and keep scrobbling and auxiliary requests opt-in. |
| Optional AI providers and configurable community backends | Verify provider terms, user opt-in, credential storage, request contents and retention policies. Publish accurate privacy disclosures for any backend the maintainer operates. Review user-uploaded content and playlist sharing rights. | Keep these actions optional and show users which provider will receive their data. |

SimpMusic's software grant covers its licensed code. The release needs separate evidence for media and service access. Leave the approval gate disabled until the maintainer can document authorization or has approved changes to the affected features.
