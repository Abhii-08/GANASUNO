# V34.1 — PCM runtime hotfix

User Logcat: `ERROR_CODE_FAILED_RUNTIME_CHECK (1004)`, `IllegalArgumentException: The source buffer is this buffer`, at `EffectsProcessor.queueInput(EffectsProcessor.kt:48)`.

The old code called `replaceOutputBuffer(0)` and then copied the input into the returned output. Media3 may poll with the shared empty buffer; when the base processor still has that shared buffer, a self-copy throws even with zero bytes. Return immediately for empty input, before obtaining or touching the output buffer. Non-empty PCM handling and existing effects are unchanged. Version name 34.1, code 39.
